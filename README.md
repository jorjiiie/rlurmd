# rlurmd 

slurmd, but uh rlurmd

Job/Compute scheduler on a single node for serializing and managing a compute queue. 

Support for CPU/RAM/GPU resource management for scripts, and tbd the rest of the features

Not built for human usage, since it's basically for Claude to not mess up running experiments

This is as much a tool as a learning exercise for me to finally do something with rust lol
